Privacy Policy — Satisfying Loops

Last updated: October 28, 2026

What data is used

When the account owner connects their TikTok account, the tool receives an access token and the account's basic profile information (open ID). These are used only to upload videos to that same account.

Storage

The token is stored privately on the owner's own server. It is never sold, shared or sent to anyone other than TikTok's official API.

Other users

The tool does not collect, store or process any data about other TikTok users or viewers.

Deletion

Access can be revoked at any time from the TikTok app (Settings → Security → Manage app permissions), which invalidates the stored token.
